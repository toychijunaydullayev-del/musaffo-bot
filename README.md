# Musaffo Chashma Tomchisi — Telegram Bot

## Railway.app orqali deploy qilish (BEPUL)

### 1-qadam: GitHub'ga yuklash
1. github.com ga kiring (ro'yxatdan o'ting)
2. "New repository" bosing → nom bering (masalan: musaffo-bot)
3. Barcha fayllarni yuklang

### 2-qadam: Railway'ga ulash
1. railway.app ga kiring → "Login with GitHub"
2. "New Project" → "Deploy from GitHub repo"
3. musaffo-bot repo'ni tanlang
4. "Variables" bo'limiga o'ting:
   - BOT_TOKEN = tokeningiz
   - (yoki to'g'ridan kodda yozilgan bo'lsa shart emas)
5. Deploy tugmasini bosing ✅

Bot 24/7 ishlaydi!
